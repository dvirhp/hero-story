# Original StoryForge artwork

Six SVG scenes authored as code for this project: whale, moon, alphabet, hero, family and garden. `hero-striped.svg` is an original outfit variant of the hero scene used by the schema-driven template preview. No third-party assets, AI generation or Wonderbly imagery used. These source assets are part of the project and may be edited with it. Text and book cover typography are rendered separately by React for localization. Illustrations are demonstration content, not generated story images.
